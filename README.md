# Spoyt App 🏋️

**Spoyt** - אפליקציית תכנון אימונים | Fitness Workout Planning App

Built with React.js as part of the Full-Stack AI Development course (Module 6 - Frontend Development).

## About the App

Spoyt helps fitness trainers and athletes create personalized workout plans with matching music playlists.

**Key Features:**
- 📋 Create and manage workout plans
- 🏃 Exercise library categorized by type and difficulty
- 🎵 Link music playlists to workout plans
- 👤 User profiles and personal dashboard
- 📱 Responsive design (mobile-first)

## Tech Stack

- React.js with React Router
- CSS Variables (Design System)
- Component-based architecture
- Dummy/placeholder data (no backend connection)

- **Primary Color:** #4CAF50 (Green)
- **Background:** #1a1a2e (Dark)

- **Direction:** RTL (Right-to-Left)
